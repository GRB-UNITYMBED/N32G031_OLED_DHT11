==================================================
Prompt 1: ดัชนีความสบาย (Heat Index & Comfort Level)
==================================================
ช่วยเขียนโค้ดใน main.c สำหรับไมโครคอนโทรลเลอร์ Nations N32G031 เพื่ออ่านค่าจากเซ็นเซอร์ DHT11 และแสดงผลบนจอ OLED ขนาด 128x32 โดยมีข้อกำหนดดังนี้อย่างเคร่งครัด:

1. การตั้งค่า Hardware & Library:

ใช้ N32G031 Standard Peripheral Library (SPL)
Include ไฟล์ที่จำเป็น: n32g031.h, n32g031_rcc.h, n32g031_gpio.h, utils.h, oled.h, dht11.h, <stdio.h>
สร้างฟังก์ชัน led_init() เพื่อตั้งค่าขา PB1 เป็น Output สำหรับ LED โดยต้องใช้ Macro ของ N32 คือ GPIO_MODE_OUTPUT_PP (ห้ามใช้ของ STM32)
2. ลอจิกการประเมินสภาพแวดล้อม (Comfort Level):

ใช้ if-else ประเมินจากอุณหภูมิ (T) และความชื้น (H):
Warning: T >= 35 หรือ (T >= 32 และ H >= 70)
Hot: T >= 30
Cool: T <= 22
Comfort: H อยู่ระหว่าง 40 ถึง 70
Normal: นอกเหนือจากเงื่อนไขด้านบน
3. การแสดงผลบนจอ OLED (สำคัญ: จอขนาด 128x32):

ห้ามแสดงผลเกิน Y=16 เพราะข้อความจะล้นจอและวนกลับไปทับด้านบน
บรรทัดแรก (Y=0): แสดงอุณหภูมิและความชื้นในบรรทัดเดียวกัน รูปแบบ "T:%02dC H:%02d%% "
บรรทัดที่สอง (Y=16): แสดงสถานะ รูปแบบ "Stat: %s"
4. การทำงานใน Main Loop:

อ่านค่า DHT11 ทุกๆ 2 วินาที
ถ้าอ่านสำเร็จ: อัปเดตจอ OLED และสั่งกระพริบ LED ที่ขา PB1 โดยใช้ Direct Register (GPIOB->PBSC = (1U << 1); ติด 100ms และ GPIOB->PBC = (1U << 1); ดับ 1900ms)
ถ้าอ่านล้มเหลว: เคลียร์จอ แสดงคำว่า "SENSOR ERROR" ที่ Y=0, สั่งดับ LED และ delay 2000ms

Prompt 2: ระบบบันทึกสถิติอุณหภูมิสูงสุด (Max) และต่ำสุด (Min)
==================================================
ช่วยอัปเกรดโค้ด main.c โดยเพิ่มระบบบันทึกสถิติอุณหภูมิสูงสุด (Max) และต่ำสุด (Min) ตั้งแต่เปิดเครื่อง โดยมีข้อกำหนดดังนี้:

ลอจิกการเก็บสถิติ:

สร้างตัวแปร Global เพื่อเก็บค่า max_temp (ค่าเริ่มต้น 0) และ min_temp (ค่าเริ่มต้น 100)

เมื่ออ่านค่า DHT11 สำเร็จ ให้ใช้เงื่อนไข if เพื่อตรวจสอบและอัปเดตค่า max_temp และ min_temp

การแสดงผลบนจอ OLED (ขนาด 128x32):

ให้ลบโค้ดส่วนที่แสดงหน้าจอเริ่มต้น (Splash Screen) ที่มีข้อความเช่น "created by biw" รวมถึงการหน่วงเวลาตอนเปิดเครื่องออกทั้งหมด

บรรทัดแรก (Y=0): แสดงค่าปัจจุบัน รูปแบบ T:%02dC H:%02d%% 

บรรทัดที่สอง (Y=16): แสดงค่าสถิติ รูปแบบ Min:%02d Max:%02d 

ห้ามแสดงผลเกิน Y=16 และระวังเว้นวรรคต่อท้ายข้อความเพื่อเคลียร์เศษตัวอักษรเก่า

ข้อควรระวัง (Constraints):

ใช้ฟังก์ชัน OLED ที่มีอยู่แล้ว (เช่น OLED_ShowString) ห้ามแก้ไลบรารี OLED

โค้ดส่วนการทำงานของ LED และการเช็ก Error จากข้อก่อนหน้ายังต้องทำงานได้ตามปกติ

Prompt 3: ระบบแจ้งเตือนไฟกระพริบแบบ Non-blocking ด้วย Direct Register
==================================================
ช่วยเขียนโค้ด main.c สำหรับไมโครคอนโทรลเลอร์ Nations N32G031 (Bare-metal C) โดยมีระบบอ่านค่าเซนเซอร์ DHT11, แสดงผลบนจอ OLED และมีระบบไฟแจ้งเตือน LED ที่ขา PB1 โดยมีข้อกำหนดอย่างเคร่งครัดดังนี้:

1. การแสดงผลบนจอ OLED:
- ไม่ต้องมีหน้าจอ Splash Screen (ไม่ต้องแสดงชื่อคนทำหรือหน่วงเวลาตอนเริ่มต้น)
- แสดงค่า Temp, Humi, Min, Max โดยใช้คำนำหน้าสั้นๆ เพื่อไม่ให้ข้อความตกขอบจอ เช่น "Temp:", "Humi:", "Min:", "Max:"
- ระวังการใส่ Spacebar (ช่องว่าง) ต่อท้ายในฟังก์ชัน sprintf ให้ใส่แค่พอดี ไม่ให้ความยาว string ทะลุขอบจอ

2. ระบบแจ้งเตือน LED (PB1) ด้วย Direct Register:
- ตั้งค่าขา PB1 เป็น Output Push-Pull โดยใช้ Direct Register ของ N32G031 เท่านั้น
- ชื่อ Register ที่อนุญาตให้ใช้: RCC->APB2PCLKEN (ห้ามมีตัว R ต่อท้าย), GPIOB->PMODE, GPIOB->POTYPE, GPIOB->PUPD, GPIOB->PBC, GPIOB->PBSC, GPIOB->POD
- ห้ามใช้ Register POSPEED (เพราะ N32G031 ไม่มี Register นี้แยกต่างหาก)
- ห้ามใช้ HAL หรือฟังก์ชันของ Arduino เด็ดขาด

3. ลอจิกการทำงานแบบ Non-blocking (สำคัญมาก):
- ห้ามใช้ฟังก์ชัน get_systick_ms() เพื่อหลีกเลี่ยงปัญหา Implicit Declaration
- ให้ใช้เทคนิค "Loop Counter (ตัวแปรนับรอบ)" แทน โดยใน while(1) ให้มี delay_ms(100) เพียงตัวเดียวเป็นฐานเวลา (1 tick = 100ms)
- การอ่าน DHT11: ให้อ่านค่าทุกๆ 2 วินาที (นับ counter ให้ครบ 20 รอบ) เพื่อป้องกันปัญหาเซนเซอร์ Error จากการอ่านค่าถี่เกินไป
- การกระพริบ LED: ให้เช็คเงื่อนไขทุกๆ 200ms (นับ counter ให้ครบ 2 รอบ)

4. เงื่อนไขการแจ้งเตือน (Alert Conditions):
- ถ้าอุณหภูมิ (last_temp) >= 25 องศาเซลเซียส หรือ เซนเซอร์อ่านค่าพลาด (Error) -> ให้ LED ที่ PB1 กระพริบแบบ Toggle
- ถ้าอุณหภูมิต่ำกว่า 25 องศาเซลเซียส และ เซนเซอร์ทำงานปกติ -> ให้สั่งปิด LED ค้างไว้
- หากเซนเซอร์ Error ให้แสดงคำว่า "Error" บนจอ OLED ในบรรทัด Temp และ Humi ด้วย

Prompt 4: กราฟเส้นคู่แบบเรียลไทม์ (Mini Oscilloscope)
==================================================
ช่วยเขียนโค้ดใน main.c สำหรับ N32G031 เพื่อแสดงผลค่าอุณหภูมิและความชื้นจากเซ็นเซอร์ DHT11 ขึ้นจอ OLED (128x64) เป็น 'กราฟเส้นคู่แบบเรียลไทม์' (Scrolling Dual Line Graph) สไตล์ Mini Oscilloscope ให้หน่อย

ความต้องการทางเทคนิค (Requirements):

สร้าง Framebuffer ขนาด 128x8 bytes (1024 bytes) ใน main.c

ใช้ Array เก็บประวัติค่า Temp และ Humi ขนาด 128 จุด โดยใช้ลอจิก Shift ข้อมูลไปทางซ้ายเมื่ออ่านค่าใหม่ได้

วาดกราฟโดยใช้ Bresenham's Line Algorithm เพื่อให้เส้นกราฟทั้งสองเส้นเป็นเส้นทึบที่เชื่อมต่อกันอย่างเรียบเนียน

สร้างพื้นหลังเป็นตาราง Grid แบบ 'เส้นประ' (Dotted Lines) ทั้งแนวตั้ง (เว้นระยะ 32 พิกเซล) และแนวนอน (เว้นระยะ 16 พิกเซล) โดย Map ช่วงค่าให้พอดีกับความสูง 64 พิกเซลของจอ

แสดง Text ค่าปัจจุบันทับลงบนกราฟ (HUD Overlay) ที่มุมซ้ายบน

ข้อควรระวังและวิธีป้องกัน Error (Strict Constraints):

ห้าม include <string.h> และ <stdlib.h> เด็ดขาด เพื่อป้องกัน Toolchain Error (strings.h: No such file or directory)

ให้เขียนฟังก์ชัน my_abs() ขึ้นมาใช้เองแทน abs() และใช้ for loop ในการเคลียร์ Framebuffer แทนการใช้ memset()

ห้ามแก้ไขไฟล์ oled.c หรือ oled.h ในการส่ง Framebuffer ขึ้นจอ ให้ใช้เฉพาะฟังก์ชัน Public ที่มีอยู่แล้ว (เช่น OLED_DrawBitmap, OLED_ShowString)

ให้แก้ไขไฟล์ Makefile โดยเพิ่ม --specs=nano.specs ใน LDFLAGS เพื่อป้องกัน Linker Error จากการใช้ sprint
